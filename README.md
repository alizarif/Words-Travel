# Words Travel: The Global Transmission of Central Bank Language

# Replication files

- **01_scoring.ipynb** prepares the raw texts and generates lexical scores, LLM ratings, and embeddings. Saved results are provided, so it does not need to be rerun.
- **02_analysis.ipynb** uses the saved scores to reproduce the main paper and appendix results, tables, and figures in order.

## Data archives

- **data/raw_data.zip** is not included because the underlying texts are restricted. Request access from the [Monetary Policy Statement Database team](https://centralbanktexts.github.io/contact.html).
- **data/scored_data.zip** contains saved scores, embeddings, model responses, and supporting inputs.
- **data/analysis_outputs.zip** contains analysis results, table data, and verification reports.

Keep the folder structure unchanged. The notebooks handle the ZIP files automatically.
